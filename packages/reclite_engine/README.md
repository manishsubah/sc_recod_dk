# reclite_engine

Native recording engine for RecLite (Flutter plugin, macOS + Windows).

- Contract: `pigeons/engine_api.dart` (regenerate with `dart run pigeon --input pigeons/engine_api.dart`).
- macOS (Swift): `macos/reclite_engine/Sources/reclite_engine/`
- Windows (C++): `windows/`

See `../../docs/PLAN.md` for the design.
